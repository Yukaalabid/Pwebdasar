# Portofolio Muhammad Yuka Al Abid

Portofolio pribadi untuk menampilkan profil, riwayat pendidikan, keahlian,
dan proyek perkuliahan.

## Isi folder

- `index.html` — struktur dan konten halaman
- `style.css` — warna, tata letak, dan tampilan responsif
- `script.js` — tahun otomatis serta fitur membuat dan menyalin draf pesan
- `readme.md` — penjelasan proyek

## Cara menjalankan

1. Simpan keempat file dalam satu folder.
2. Buka `index.html` menggunakan browser.
3. Pastikan `style.css` dan `script.js` berada di folder yang sama dengan
   `index.html`.

Kamu juga bisa membuka foldernya di VS Code dan menjalankan `index.html`
menggunakan Live Server.

## Tentang formulir kontak

Formulir hanya membuat draf pesan dan membantu menyalinnya. Formulir belum
mengirim pesan atau menyimpan data karena belum terhubung ke server.

## Kaitan dengan tugas Pemrograman Web Dasar

Halaman memakai elemen semantik `header`, `main`, `section`, dan `footer`.
Riwayat pendidikan disajikan dalam tabel, sedangkan keahlian menggunakan
daftar. CSS dan JavaScript merupakan pengembangan tampilan dan interaksi
dari halaman profil HTML awal.

Jika dosen meminta pengumpulan Tugas 1 dalam bentuk HTML murni, simpan
versi awal tanpa CSS dan JavaScript secara terpisah.
